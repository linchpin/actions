# Agent instructions

## This repository is public

Everything here is world-readable: files, code comments, docs, commit messages,
branch names, PR titles and bodies, issues, release notes and `CHANGELOG.md`.
Never name a client or leave enough to identify one. Describe the problem fixed
or the feature added, not who it was for.

- No client names, initials, repo names, domains, hostnames, site or server IDs,
  GitHub orgs, or links to their runs.
- No client task keys or titles. A client task's prefix is the client's
  initials, so the key alone names them. Scope commits and branches to a
  `LINCHPIN-` task (see `.clickup.json`) or `NO-TASK`.
- Examples use placeholders: `linchpin/example-site`, `www.example.com`,
  `123456`.
- Write "a client site" or "one caller", not which one. Evidence from a client
  repo (failed runs, plugin lists, error output) belongs in the private task.
